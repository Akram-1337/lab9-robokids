# RoboKids — Children's Robotics School (Lab Work 9)

Responsive landing page concept for ICT6001 Laboratory Work No. 9.

## Files
- `index.html` — semantic HTML structure and small JavaScript for the theme switch.
- `style.css` — responsive layout, CSS Grid, Flexbox, mobile burger menu and light/dark styling.
- `images/` — folder reserved for exported assets (SVG/WebP).

## Run locally
Open `index.html` in a web browser, or use Live Server in Visual Studio Code.

## Publish with GitHub Pages
1. Create a **public** repository on GitHub.
2. Upload `index.html`, `style.css`, and the `images` folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. Wait for deployment and open the published URL shown in Settings → Pages.

## Suggested commit sequence
1. `feat: add semantic robotics school landing page`
2. `feat: add responsive grid and mobile navigation`
3. `feat: add contact form and theme switch`
